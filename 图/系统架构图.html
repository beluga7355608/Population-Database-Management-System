六、架构文字说明

6.1 系统概述

人口数据库管理系统采用 B/S 架构（Browser/Server），基于前后端分离模式设计。前端使用 Vue.js + Element UI 构建单页应用（SPA），后端基于 Spring Boot + MyBatis 提供 RESTful API 服务，数据持久化采用 MySQL 8.0+ 关系型数据库。系统面向系统管理员和户籍工作人员两类角色，覆盖常住人口、流动人口、重点人口、户口立户、迁入迁出、证件管理等九大核心业务模块。

6.2 各层组件说明

🖥️ 客户端层 (Client Layer)

  • 运行载体：Chrome / Edge / Firefox 等主流浏览器
  • 职责：提供用户交互界面，支持户籍业务办理、数据查询、报表导出打印
  • 外设支持：激光打印机（台账打印）、扫描仪（材料上传）

🔒 安全网关层 (Security Gateway)

  • Spring Security：实现基于角色的访问控制（RBAC），区分管理员与普通工作人员权限
  • IP 白名单：仅允许局域网内授权 IP 访问系统接口，拒绝外部非法请求
  • HTTPS/TLS 加密：前后端通信全程加密，防止户籍数据在网络链路中被窃取或篡改
  • 会话管理：30分钟无操作自动超时退出，防止账号被他人冒用
  • 文件安全校验：上传材料时进行病毒扫描和文件类型校验

🎨 前端展示层 (Presentation Layer)

  • Vue.js 2.x/3.x：构建响应式单页应用，组件化开发，支持模块独立加载
  • Element UI：提供表格、表单、弹窗、导航等标准化 UI 组件，保证界面风格统一
  • Vue Router：前端路由管理 + 路由守卫，根据角色动态加载功能菜单，拦截越权访问
  • Axios：HTTP 客户端，封装请求/响应拦截器，统一处理 Token 携带、错误提示
  • 表单校验：前端实现身份证号、手机号、日期等字段格式校验，拦截无效提交

⚙️ 业务逻辑层 (Business Logic Layer)

  • Controller 控制层：接收前端请求，参数校验，调用 Service 层处理业务
  • Service 服务层（10个核心服务）：
    服务名称对应模块核心功能
    LoginService登录认证账号校验、Token签发、角色权限加载、会话管理
    HouseholdService户口立户立户申请、材料核验、多级审批、户口档案生成
    ResidentService常住人口信息录入、变更维护、多维查询、统计报表
    TransferService户口迁入/迁出迁入迁出申请、审批流转、户籍状态同步
    FloatingPopService流动人口暂住登记、到期提醒、注销管理
    KeyPopService重点人口专项建档、动态跟踪、权限管控、预警提醒
    CertificateService证件管理证件办理、挂失补办、状态管理
    AuditLogService操作日志全维度操作记录、不可篡改、多条件查询
    BackupService数据备份自动+手动备份、全量+增量、快速恢复
    NotificationService消息提醒待办推送、到期提醒、站内弹窗

📦 数据访问层 (Data Access Layer)

  • MyBatis：ORM 映射框架，通过 XML/SQL 注解实现 Java 对象与数据库表的映射
  • Druid 连接池：管理数据库连接，提供 SQL 监控和慢查询分析
  • Spring 事务管理：保证户口迁入迁出、审批等关键业务的原子性，防止数据不一致

🗄️ 数据存储层 (Data Storage Layer)

  • MySQL 8.0+ 主数据库：
    • 存储全部人口户籍数据、业务台账、审批记录、操作日志
    • 支持事务（InnoDB）、索引优化、主键外键约束，保障数据完整性
    • 敏感字段（身份证号、联系方式）脱敏存储
    • 数据永久留存，不提供物理删除，仅做状态标记
  • Redis（可选）：用于分布式 Session 管理和热点数据缓存，提升系统响应速度
  • 文件存储：保存户口迁入/迁出证明材料、证件附件、数据库备份文件
  • 备份策略：定期全量备份 + 增量备份，备份文件加密独立存放，支持快速恢复

🏗️ 基础设施层 (Infrastructure Layer)

  • Tomcat 8.5+：Servlet 容器，部署 Spring Boot 打包的 WAR/JAR 应用
  • JDK 21：Java 运行时环境
  • Maven 3.6+：项目构建与依赖管理
  • Node.js 14+：前端项目构建打包（npm/webpack）
  • 硬件要求：CPU i5+ / 内存 16G / 硬盘 80G / 100Mbps 局域网
  • UPS 不间断电源：防止异常断电导致数据丢失

6.3 网络与安全设计

安全层面措施说明
数据存储安全敏感字段脱敏 + 权限控制身份证号、联系方式脱敏存储；仅授权运维账号可直连数据库
访问控制安全Spring Security + RBAC区分管理员/工作人员角色，重点人口模块设置专属高权限
网络传输安全HTTPS 加密 + IP 白名单前后端通信加密；拒绝非法外部 IP 访问，拦截恶意请求
应用审计全维度操作日志记录操作人、时间、IP、模块、内容，日志不可删除篡改
会话安全30分钟超时 + 错误锁定自动退出 + 多次密码错误锁定账号，防暴力破解
业务约束状态机 + 流程引擎杜绝跳过环节、越级操作、逆向办理；重复业务自动拦截
数据安全水印 + 防泄密导出/打印涉密文档时自动添加操作人+时间水印
